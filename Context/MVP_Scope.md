\# MVP\_SCOPE.md

\#\# Goal

Build only the first working product spine:

Photo/voice/manual input  
→ draft  
→ confirmation/correction  
→ business event  
→ stock/task/alert  
→ evidence-backed simple answer

\#\# In Scope

\- Auth and mill setup  
\- Document upload  
\- Truck sheet draft extraction  
\- Manual fallback entry  
\- Voice paddy inward draft  
\- Confirmation screen  
\- Correction memory  
\- Paddy lot creation  
\- Confirmed stock event  
\- Missing-data tasks  
\- Basic mismatch alert  
\- By-product sale entry  
\- Low-rate alert using historical confirmed sales  
\- Expense entry  
\- Basic CA export preview  
\- Simple Ask/Search for MVP questions

\#\# Out of Scope

\- Full ERP  
\- Full accounting  
\- Tally integration  
\- GST filing  
\- Full OPMS automation  
\- Automatic government confirmation  
\- Complex dashboards  
\- Custom trained handwriting model  
\- Multi-mill SaaS billing/admin  
\- Prediction engine  
\- Advanced vector search
